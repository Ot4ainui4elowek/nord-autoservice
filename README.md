# Автосервис «Норд» — лендинг

Одностраничный сайт автосервиса «Норд» (Тирасполь, ул. Шевченко 84Б, у заправки «Шериф»).
Чистый HTML/CSS/JS, без сборки — подходит для GitHub Pages.

## Локальный просмотр

```bash
python -m http.server 8765
```

Открыть http://127.0.0.1:8765/

## Что где менять

- Тексты, телефон, услуги, часы работы — `index.html` (телефон встречается в нескольких местах и в блоке `application/ld+json`).
- Цвета и вёрстка — `styles.css` (переменные в `:root`).
- Фото — папка `img/`. Сейчас стоят тематические фото с Unsplash (бесплатная лицензия); лучше заменить на реальные фото сервиса с теми же именами файлов.
- Точка на карте — координаты `46.8545,29.6125` в `index.html` (iframe, ссылки на карты, schema.org).

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
